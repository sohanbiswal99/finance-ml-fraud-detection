# finance-ml-fraud-detection
# 💳 Financial Fraud Detection using Machine Learning

> 🚨 A Machine Learning project that identifies whether a financial transaction is **Fraudulent** or **Legitimate**.

---

## 🎯 About the Project

This project uses Machine Learning to analyze financial transaction patterns and detect potentially fraudulent transactions.

**Prediction:**

🟢 `0` → Legitimate Transaction  
🔴 `1` → Fraudulent Transaction

---
